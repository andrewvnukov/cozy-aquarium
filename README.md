# Тёплый Аквариум / Cozy Aquarium

Idle-коллекционер про уютный аквариум под Яндекс Игры. Один статический
`index.html` (canvas + HUD + вся логика), процедурный звук в `sfx.js`,
без бандлера и внешних зависимостей.

Петля: покормить (тап-доход) → накопить жемчуг → завести новую рыбку
(плавает, даёт пассивный доход) → улучшения → пересадка аквариума (престиж).

## Экономика

| Что | Как устроено |
| --- | --- |
| Виды рыб | 12 ступеней, доход ×1,6–1,75 за ступень, цена ×3,0–3,6 |
| Улучшения | корм (тап, макс. 8), аэратор (+25% пассива), водоросли (−5% цены, макс. 8) |
| Престиж | «пересадить аквариум»: `floor(sqrt(lifetime / 1.5M))` кораллов, +25% дохода за коралл |
| Валюты | жемчуг (обычная, обнуляется при пересадке) и кораллы (премиальная, не обнуляются) |

Два правила, на которых держится баланс:

- **`earn` против `grant`.** Заработок идёт в `S.lifetime` (метрика прогресса,
  от неё считается престиж), подарки за рекламу и ежедневку — нет. Иначе
  подарки ускоряют престиж, престиж раздувает доход, доход — следующие подарки.
- **Округление только при показе.** Доход дробный; `floor` при начислении
  съедал бы прибавку от аэратора на малых числах.

Прогон баланса: интервал между покупками растёт с ~20 с до ~35 мин, полная
коллекция — около 90 минут idle / 55 минут активной игры, первая пересадка
доступна примерно через 40 минут.

## Удержание и реклама

- **Офлайн-доход** — три независимых порога: начисляем от 1 минуты, потолок
  8 часов, окно-сводку показываем от 4 часов (потолок обязан быть больше
  порога показа, иначе появляется мёртвая зона). Множитель 0,5.
- **Ежедневная серия** — цикл из 7 дней по строке даты (`YYYY-MM-DD`), награда
  привязана к текущему темпу игрока, кораллы на 3-й и 7-й день, кнопка «×2».
- **Rewarded-слоты**: подарок (КД 90 с), доход ×2 на 5 минут, удвоение офлайна,
  удвоение ежедневки, награда за ярлык на главный экран.
- **Межстраничная** — только в естественной паузе (закрытие окна возвращения),
  с прогревом 90 с и паузой, отсчитываемой от факта показа (`wasShown`).
- **Контекстные подсказки** — отдельная от обучения система: триггеры условные,
  показываются в том числе давним игрокам, одна за раз, один раз навсегда.

## Требования площадки

`LoadingAPI.ready()` уходит ровно один раз и до того, как интерфейс станет
доступен (гейт — класс `body.ready`); язык платформы читается на каждом запуске
до первой отрисовки и нигде не сохраняется; звук глушится и на время рекламы,
и при уходе вкладки в фон; сейв дожимается с `flush` на `visibilitychange` и
`pagehide` с собственным троттлом 3 с; лидерборд пишется через `setScore`
(с фолбэком на устаревший `setLeaderboardScore`) только для авторизованного
игрока и не чаще раза в секунду.

## Тест

```
npm install
node test/smoke.mjs
```

Playwright-тест поднимает игру с моком Yandex SDK (подменяется через
`addInitScript` до загрузки скриптов) и проверяет петлю, экономику, все
rewarded-слоты, офлайн, ежедневку, престиж, миграцию старых сейвов,
повреждённые сейвы, подсказки и GameReady. Если в окружении лежит заранее
скачанный Chromium другой сборки, путь к нему передаётся через `PW_CHROMIUM`.

## Сборка билда

`index.html` должен лежать в корне zip. Внешние ресурсы — только шрифты
Google Fonts и `yandex.ru/games/sdk/v2`.
