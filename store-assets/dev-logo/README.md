# Логотип разработчика — варианты

Знак для страницы разработчика в консоли Яндекс Игр.
Три набора: **яркий** (основной), «пастельный» универсальный и «аквариумный».

Общее у всех: круглая форма и один крупный силуэт по центру — так знак
не рассыпается ни в 512 px, ни в 24 px. Названия студии внутри нет:
его можно поставить рядом на странице разработчика или вписать
в отдельную версию.

## Яркий набор (рекомендую)

Сочные градиенты, белые силуэты, лучи из центра. Заметно в ленте
и не привязано ни к одной игре.

| Файл | Вариант | Цвет | О чём |
|------|---------|------|-------|
| `bright-star.png`  | Звезда           | коралл → малина | Самый универсальный знак «игры» |
| `bright-cat.png`   | Кот              | розовый         | Уют в сочной подаче |
| `bright-pad.png`   | Геймпад          | голубой → синий | Прямо говорит «игры», лучший силуэт в 24 px |
| `bright-heart.png` | Сердце           | розово-фиолет.  | Тепло + яркость |
| `bright-sun.png`   | Солнце с улыбкой | жёлтый → оранж. | Самый светлый и добрый |
| `bright-moon.png`  | Месяц и звёзды   | фиолетовый      | Ночной, хорошо контрастирует со списком |
| `bright-blob.png`  | Улыбка-капля     | лайм → зелёный  | Простейший силуэт, читается лучше всех |
| `bright-bolt.png`  | Молния           | мятный          | Энергия, острый узнаваемый контур |

`all-logos-bright.png` — лист сравнения (крупно + проверка в 40 и 24 px).

Исходник — `logo-bright.html`, знаки рисуются кодом на чистом SVG:

```
logo-bright.html?logo=star&size=512
```

Ключи: `star`, `cat`, `pad`, `heart`, `sun`, `moon`, `blob`, `bolt`.
Градиенты правятся в `defs`, плотность лучей — в вызове `rays(n, opacity, rot)`.

## Пастельный универсальный набор

Тот же смысл, что у яркого набора, но в приглушённой «бумажной» палитре:
тёплый фон, чернильный контур `#3A3140`, мягкие блики.

| Файл | Вариант | О чём |
|------|---------|-------|
| `uni-cat.png`   | Спящий кот клубком | Самый прямой символ уюта, тёплый фон |
| `uni-mug.png`   | Кружка с паром     | «Домашний вечер», хорошо читается мелким |
| `uni-house.png` | Дом с тёплым окном | Ночь снаружи, свет внутри |
| `uni-pad.png`   | Геймпад            | Прямо говорит «игры», лучший силуэт в 24 px |
| `uni-moon.png`  | Месяц и звёзды     | Ночное небо, самый «тихий» вариант |
| `uni-lamp.png`  | Фонарик            | Тёплый свет в темноте |
| `uni-hills.png` | Солнце над холмами | Спокойный пейзаж, дневной вариант |
| `uni-heart.png` | Пиксельное сердце  | «Игры» + тепло, максимально простой силуэт |

`all-logos-universal.png` — лист сравнения (крупно + проверка в 40 и 24 px).

Исходник — `logo-universal.html`, знаки рисуются кодом на чистом SVG:

```
logo-universal.html?logo=cat&size=512
```

Ключи: `cat`, `mug`, `house`, `pad`, `moon`, `lamp`, `hills`, `heart`.
Палитра правится в `defs` и константах `INK` / `CREAM` в начале скрипта.

Завязан на «Тёплый Аквариум» и «Сладкую Банку» — годится, если студия
останется в этой теме, иначе лучше брать универсальный набор.

| Файл | Вариант | О чём |
|------|---------|-------|
| `logo-jar.png`   | Банка с рыбкой        | Склейка двух игр серии |
| `logo-wave.png`  | Волна и солнце        | Нейтральный «уютный» знак |
| `logo-pearl.png` | Жемчужина в раковине  | Перекликается с валютой аквариума |
| `logo-mug.png`   | Кружка с рыбкой       | Самый «домашний» вариант серии |
| `logo-pad.png`   | Геймпад в глубине     | Прямо говорит «игры» |
| `logo-drop.png`  | Капля с рыбкой        | Минималистичный силуэт |

`all-logos.png` — лист сравнения. Исходник — `logo.html`,

## Как перерендерить

Из папки игры (нужен `node_modules` с Playwright):

```js
// node <script>.mjs
import { chromium } from 'playwright';
const b = await chromium.launch();
const p = await b.newPage({ viewport: { width: 512, height: 512 } });
await p.goto('file:///абсолютный/путь/logo-bright.html?logo=star&size=512');
await p.screenshot({ path: 'bright-star.png' });
await b.close();
```
