# Логотип разработчика — варианты

Восемь вариантов знака для страницы разработчика в консоли Яндекс Игр.
Стиль общий с играми серии: тёплая «бумага», чернильный контур, мягкие блики.

| Файл | Вариант | О чём |
|------|---------|-------|
| `logo-jar.png`   | Банка с рыбкой | Склейка двух игр серии: банка из «Сладкой Банки» + рыбка из «Тёплого Аквариума» |
| `logo-wave.png`  | Волна и солнце | Нейтральный «уютный» знак, не привязан к жанру |
| `logo-pearl.png` | Жемчужина в раковине | Перекликается с валютой аквариума |
| `logo-mug.png`   | Кружка с рыбкой | Самый «домашний» вариант серии |
| `logo-pad.png`   | Геймпад в глубине | Прямо говорит «игры», лучше всех читается мелким |
| `logo-drop.png`  | Капля с рыбкой | Минималистичный силуэт |
| `logo-home.png`  | Дом-аквариум | «Уютный дом для игр» |
| `logo-mono.png`  | Монограмма «А» | Буква + волна + рыбка |

`all-logos.png` — лист сравнения (крупно + проверка в 40 и 24 px).

## Исходник

`logo.html` — генератор на чистом SVG, знаки рисуются кодом.
Перерендерить любой вариант в нужном размере:

```
logo.html?logo=jar&size=512
```

Ключи: `jar`, `wave`, `pearl`, `mug`, `pad`, `drop`, `home`, `mono`.
Цвета правятся в `defs` и константах `INK` / `PAPER` в начале скрипта.
Текст с названием студии в знаки не входит — его можно добавить рядом
на странице разработчика или вписать в отдельную версию логотипа.
