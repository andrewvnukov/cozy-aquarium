# Логотип разработчика — варианты

Знак для страницы разработчика в консоли Яндекс Игр.
Два набора: **универсальный** (основной) и «аквариумный» (первый заход).

Общий стиль: тёплая «бумага», чернильный контур `#3A3140`, мягкие блики,
круглая форма — так знак не рассыпается ни в 512 px, ни в 24 px.
Текста с названием студии внутри нет: его можно поставить рядом
на странице разработчика или вписать в отдельную версию.

## Универсальный набор (рекомендую)

Ничего рыбного и вообще ничего привязанного к одной игре — знак работает
для любых уютных игр студии.

| Файл | Вариант | О чём |
|------|---------|-------|
| `uni-cat.png`   | Спящий кот клубком | Самый прямой символ уюта, тёплый фон |
| `uni-mug.png`   | Кружка с паром     | «Домашний вечер», хорошо читается мелким |
| `uni-house.png` | Дом с тёплым окном | Ночь снаружи, свет внутри |
| `uni-pad.png`   | Геймпад            | Прямо говорит «игры», лучший силуэт в 24 px |
| `uni-moon.png`  | Месяц и звёзды     | Ночное небо, самый «тихий» вариант |
| `uni-lamp.png`  | Фонарик            | Тёплый свет в темноте |
| `uni-hills.png` | Солнце над холмами | Спокойный пейзаж, дневной вариант |
| `uni-heart.png` | Пиксельное сердце  | «Игры» + тепло, максимально простой силуэт |

`all-logos-universal.png` — лист сравнения (крупно + проверка в 40 и 24 px).

Исходник — `logo-universal.html`, знаки рисуются кодом на чистом SVG:

```
logo-universal.html?logo=cat&size=512
```

Ключи: `cat`, `mug`, `house`, `pad`, `moon`, `lamp`, `hills`, `heart`.
Палитра правится в `defs` и константах `INK` / `CREAM` в начале скрипта.

## Аквариумный набор (первая версия)

Завязан на «Тёплый Аквариум» и «Сладкую Банку» — годится, если студия
останется в этой теме, иначе лучше брать универсальный набор.

| Файл | Вариант | О чём |
|------|---------|-------|
| `logo-jar.png`   | Банка с рыбкой        | Склейка двух игр серии |
| `logo-wave.png`  | Волна и солнце        | Нейтральный «уютный» знак |
| `logo-pearl.png` | Жемчужина в раковине  | Перекликается с валютой аквариума |
| `logo-mug.png`   | Кружка с рыбкой       | Самый «домашний» вариант серии |
| `logo-pad.png`   | Геймпад в глубине     | Прямо говорит «игры» |
| `logo-drop.png`  | Капля с рыбкой        | Минималистичный силуэт |
| `logo-home.png`  | Дом-аквариум          | «Уютный дом для игр» |
| `logo-mono.png`  | Монограмма «А»        | Буква + волна + рыбка |

`all-logos.png` — лист сравнения. Исходник — `logo.html`,
ключи: `jar`, `wave`, `pearl`, `mug`, `pad`, `drop`, `home`, `mono`.

## Как перерендерить

Из папки игры (нужен `node_modules` с Playwright):

```js
// node <script>.mjs
import { chromium } from 'playwright';
const b = await chromium.launch();
const p = await b.newPage({ viewport: { width: 512, height: 512 } });
await p.goto('file:///абсолютный/путь/logo-universal.html?logo=cat&size=512');
await p.screenshot({ path: 'uni-cat.png' });
await b.close();
```
